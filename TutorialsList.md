## Online Tutorials & Courses 
A collection of online text, video, short course tutorials for different tools.

### Computer Aided Design

#### Autodesk Fusion [website](https://www.autodesk.com/solutions/design-manufacturing/fusion-tutorials)
Required that you install software on a PC. It’s a more feature rich modeler than others in that it can do top down and bottom-up design simultaneously as well as direct surface modeling. 

#### Onshape Learning Center [website](https://learn.onshape.com/)
Can create a free onshape account and work through several basic concepts. This CAD software can fully run in a web browser making it easy for many people to access. 

#### OpenFOAM [wiki](https://wiki.openfoam.com/Tutorials)
This is a powerful, but hard to set up simulation tool for mechanical and fluid simulation. It is more for research, industry, and university. FreeCAD has some plugins that can make setting up some of the cases easier. 

#### PrusaSlicer [First Print with PrusaSlicer](https://help.prusa3d.com/article/first-print-with-prusaslicer-2-9_1753)
A 3d print slicer used by prusa printers with support for a wide range of other machines.

#### KiCad [resource list](https://www.kicad.org/help/learning-resources/)
KiCad is a freely accessible electronics cad and simulation tool. 

### Software

#### OpenCV - Computer Vision [OpenCV University](https://opencv.org/university/)
They have some free short courses. One of which is covers computer vision, it’s a good intro to explore some computer vision fundamentals.

#### git - version control [git learn](https://git-scm.com/learn)
git is a version control system you can run on a website / server (like this site for example), you can also run it locally, or even completely offline using usb drives that are moved around between computers.
